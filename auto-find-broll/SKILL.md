# 自动找B-roll

把口播变成“先加法、后减法”的 B-roll 候选池：优先解决观众看不懂、看不见或感受不到的地方，再由用户从足够多的高质量候选中做删减。画面只服务于解释、举证或情绪，不为了热闹而遮挡讲者。

## 输入与时间保真

- 识别输入是纯文案、带时间码文本还是标准 SRT。保留原文顺序、原句与已有时间码。
- 纯文案以“段落 + 原句”定位；没有时间数据时绝不推算伪精确时间点。
- SRT 以字幕块为最小可信单位。跨块语义的原口播区间取首块开始到末块结束；把`原口播对应区间`与`建议插入区间`分列。
- 单一字幕块内没有字级时间戳时，建议插入区间必须写“位于字幕块内，精确入出点待听音确认”。可给建议时长，不能把建议伪装成原始时间。
- 发现重叠、倒序、缺号、空块或断轴时先标记问题；可以继续做语义分析，但不能悄悄修正时间。

## 先做加法：找全应被看见的内容

按完整意思合并相邻句后逐段判断。只要画面能让观众更快、更具体地理解，就先列为候选。重点包括：抽象观点、术语、分类、步骤、关系、系统、前后对比、选择标准、人物动作、情绪、场景、事实性信息与需要视觉参照的句子。

- 遇到定义、分类或列举，例如“人物动作场景、情绪特写、概念画面”，必须逐项提供可见的示范画面；不能只重复名词。
- 人物动作场景必须同时交代“谁、在何处、做什么”。情绪特写聚焦脸、眼神、手部或身体状态。概念画面可用光影、材质、空间、秩序、阻力或物件关系表达，不必直拍字面名词。
- 涉及网站、软件、下载、设置、文件路径或产品功能时，优先真实录屏或实际操作；库存素材不能冒充产品事实。
- 仅排除纯寒暄、没有新信息的重复连接词，及必须依赖讲者表情建立信任的关键表态。不要因为“听得懂”就停止找画面。

每个位置只选一个首要目的：`解释`、`举证`或`营造情绪`。再写出可观察的视觉命题和检索词，避免“高级职场”“女性成长”这类不可检索描述。

## 先分析表层与深层，再搜索

对每个需要 B-roll 的位置，先完成以下判断：

1. 表层含义：字面上发生什么、观众需要看见什么。
2. 深层含义：它反映的心理、关系、价值判断或工作逻辑。
3. 可选视觉隐喻：用`核心意思 / 关键物件 / 底色 / 组装顺序`描述。仅在直拍画面不足以承载抽象关系时使用。
4. 具体画面：主体、动作、环境、景别/镜头感，以及必须避开的表演感、低质感或误导元素。
5. 检索词：中文和英文各给 2–4 组，包含主体、动作、场景、镜头或地域/人群等实际筛选条件。

## 联网筛选与审核

用户要求真实素材时，实时检索并打开 Pexels、Pixabay、Mixkit Free、Coverr 的素材详情页核验。不能访问、不能验证或不符合规格时直接说明；不虚构标题、作者、链接、许可或清晰度。

- 每个位置先找 4–6 个方向不同的合格候选；结果不足则如实说明。最终每处至少有`首选`与`备选`，其余保留为`候选 3/4/5`，不为简短而过早删减。
- 首选优先“表层直达”，让观众立刻看懂原句；备选优先“深层含义/视觉隐喻”，或提供明显不同的情绪路径。两者不能只是同类画面换演员。
- 统一筛选标准：真实可信、克制不浮夸、构图光线色彩有质感、主体在竖屏中成立、无明显水印/智能裁切/AI伪真/摆拍感或语义冲突。
- 目标为原生 9:16；优先 4K，最低 1080×1920。候选阶段记录详情页显示的实际数字分辨率；下载后以本地媒体检测为准。
- 每个候选都给可打开的预览或详情页、来源平台、作者/发布方（未知则写未知）、许可提示、实际分辨率和推荐理由。

审核输出结构、时间写法和卡片字段见 [references/output-format.md](references/output-format.md)。

## 两阶段执行

### 阶段一：只供审核

先输出候选，明确首选/备选/候选及其表层或深层对应关系。结尾写明“当前未下载；确认后再统一下载”。用户没有明确确认前，不下载 MP4。

### 阶段二：确认后下载

- 仅下载用户确认的首选、备选和候选；不把“看起来合适”当作下载授权。
- MP4 的固定目录是 `D:\CODEX-b-roll素材\自动找b-roll skill教学`。先检查 D 盘存在、目录可创建且实际可写；任一步失败就停止并提示，不得改存 C 盘、工作区或其他位置。
- 按口播位置建立独立区域（子目录）；在文件名中区分`首选`、`备选`、`候选`。
- 下载后验证可解码、MP4 容器、实际宽高、时长与竖屏规格。规格低于 1080×1920、横屏强裁、实际文件与审核不符或下载失败时，标记失败并说明，不转码/放大冒充合格。
- 同一 D 盘目录保存素材清单；字段、命名与完成标准见 [references/download-and-manifest.md](references/download-and-manifest.md)。

## 输出与自检

先用 2–4 句说清配画策略、应以真实录屏替代库存素材的位置，以及主要风险。再依照输出参考交付“加法候选清单、逐位置候选、暂不配画位置、待确认事项”。

完成前确认：是否覆盖了所有理解门槛；分类句是否逐项可见；每处是否有首选与备选；来源是否为详情页；预览、实际分辨率与理由是否完整；是否区分原口播与建议插入区间；是否没有编造时间点；是否在确认前保持未下载。
