# 确认后的下载与素材清单

仅在用户明确确认下载范围后执行。

## 固定目录与停止条件

MP4 固定保存到：

`D:\CODEX-b-roll素材\自动找b-roll skill教学`

执行前依次确认：D 盘存在、目标目录存在或可在 D 盘创建、目标目录实际可写。任何一步失败都停止并告知用户；不得自行改存 C 盘、工作区或临时目录。

只下载用户确认的条目。每个口播位置使用独立子目录，例如 `B04_逐句筛选`；B04A 这类同一位置的动作/情绪/概念示例仍保留在独立区域中。

## 规格核验与命名

- 优先 MP4、原生 9:16、4K；最低 1080×1920。
- 下载后读取本地媒体元数据，检查可解码、容器、宽高、时长与帧率。
- 实测规格小于最低要求、横屏强裁、文件不可解码或与审核信息有实质差异时，标记失败并停止该条；不转码、插值、放大或伪称 4K。
- 最终文件名：`B<编号>_<首选/备选/候选>_<简短画面名>_<宽>x<高>.mp4`。

例：`B04_首选_便签分析_2160x3840.mp4`

## 素材清单

在固定目录根部保存 `素材清单.md`；需要表格处理时同时保存 `素材清单.csv`。每一条必须包含：

| 字段 | 要求 |
|---|---|
| 文件名 | 与实际磁盘文件完全一致 |
| 本地路径 | D 盘绝对路径 |
| 所在区域 | 对应 B 编号子目录 |
| 来源平台 | Pexels / Pixabay / Mixkit Free / Coverr |
| 来源链接 | 可核验的素材详情页，不是搜索页 |
| 作者/发布方 | 按详情页记录；未知明确写未知 |
| 对应口播原句 | 原文引用，不改写 |
| 原口播 SRT 时间码 | 直接引用输入；纯文案写段落锚点 |
| 建议插入区间 | 与审核稿一致；无字级时间戳时不虚构 |
| 建议使用时长 | 编辑建议 |
| 选择级别 | 首选 / 备选 / 候选 3 等 |
| 本地实测分辨率与时长 | 下载后实际检测结果 |
| 推荐理由 | 与原句的具体对应关系 |
| 授权提示 | 下载时页面显示的许可信息，提示发布前复核 |
| 下载状态 | 已下载并核验 / 失败 / 待重新确认 |

## 交付报告

报告已下载文件、固定目录、本地实测规格与时长；单列下载失败或规格不符的条目及原因。素材清单中的文件名必须与磁盘一一对应。
